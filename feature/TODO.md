## 需要较大改动

### 流式档的定点编辑与撤销 / 重做

流式档目前是纯只读。它不在文档表里建常规文档对象，因此既没有可编辑的文本结构，
也没有撤销栈。

要支持编辑，需要引入第三种文档表示——**只建索引 + 稀疏补丁**——
并让撤销栈、坐标换算、保存三条路径都适配它。这是目前剩余工作里最大的一块。

- [ ] 定点操作：删除选中行区间、指定位置插入、查找替换、按过滤结果导出、追加
- [ ] 上述操作的撤销 / 重做

### 长期持有文件映射的副作用

流式档为了随机访问行内容，会一直映射着目标文件。在 Windows 上这会占住文件句柄，
**可能导致用户自己的日志轮转工具无法轮转正在查看的文件**。

- [ ] 改为按需读取（定位 + 读取视口那几 KB）而不是长期持有映射，
      或在检测到轮转失败时主动释放

## 不做（记录在此以免反复提出）

- **Markdown 下划线与前景 / 背景色工具栏按钮**：Markdown 无对应语法，只能靠内联 HTML，
  而预览会把裸 HTML 转义成文本，做出来只会在预览里显示成可见的标签字面量。
  同理不绑定 `Ctrl+U`。
- **自绘无边框标题栏**：自绘方案在 Windows 上会白屏，收益不足以支撑排查与维护成本，
  长期使用原生标题栏。
- **代码签名（Authenticode / Apple 公证）**：不上架，成本不划算。
  用户首次运行时手动放行即可，装好后的自动更新不受影响。
  注意这与更新包自身的签名校验是两回事，后者已实现且不可绕过。
