# Fak

一个跨平台的桌面代码 / 文本编辑器，面向**日常改配置、翻日志、对比文件**这类场景。

不做 IDE，不装插件，不登账号。打开就能用，关掉不留后台。

## 它擅长什么

- **打得开大文件。** 1 GB 的日志不会把它卡死——超过阈值时自动切换到流式查看，
  只加载你正在看的那几百行，同时保留查找、过滤、跟随；过滤结果可以完整导出，
  查找替换可以先预览再另存为新文件，源日志不会被修改。
- **认得出中文编码。** GBK、GB2312、Big5、带不带 BOM 的 UTF-8/16 都能自动探测，
  探测不准时可以指定编码重新打开，不会存成一堆问号。
- **改动可回退。** 保存是原子的（不会留半截文件），未保存内容会周期性备份，
  崩溃或断电后下次启动能恢复。跨文件替换必须先看预览再落盘。
- **键盘能走完全程。** 每一个功能都能在命令面板（`Ctrl/⌘+Shift+P`）里按名字搜到。

## 平台

Windows 10+、macOS 11+。Linux 可以自行构建，但未提供安装包。

## 安装

到 [Releases](https://github.com/FrankJian/fak/releases/latest) 下载对应平台的安装包。

本应用**未做代码签名**，首次运行时：

- Windows：SmartScreen 会拦一下，点「更多信息 → 仍要运行」。
- macOS：右键点应用图标选「打开」，而不是双击。

装好之后，应用内的自动更新不再需要这些额外步骤。

## 快速上手

打开文件的方式：拖进窗口、`Ctrl/⌘+O`、或在文件管理器里右键「用 Fak 打开」
（Windows 需先到「设置 → 常规」里注册一次）。

几个值得先知道的入口：

| 想做什么         | 怎么做                                                         |
| ---------------- | -------------------------------------------------------------- |
| 找任何功能       | `Ctrl/⌘+Shift+P` 打开命令面板，按名字搜（支持拼音首字母）      |
| 在当前文件里找   | `Ctrl/⌘+F`                                                     |
| 在整个文件夹里找 | `Ctrl/⌘+Shift+F`                                               |
| 按文件名快速打开 | `Ctrl/⌘+P`                                                     |
| 跳到某一行       | `Ctrl/⌘+G`                                                     |
| 对比两个文件     | 在标签上右键「设为对比源」，再到另一个标签右键「与对比源比较」 |
| 只看含关键词的行 | 命令面板搜「过滤」                                             |
| 清洗超大日志     | 在流式查找条选择「替换后另存」，预览后写入新文件               |
| 跟着日志滚       | 打开大日志后，工具栏上的跟随按钮                               |

## 常用快捷键

修饰键：Windows/Linux 用 `Ctrl`，macOS 用 `⌘`。

| 快捷键                 | 动作                       |
| ---------------------- | -------------------------- |
| `Ctrl/⌘+N` / `O` / `S` | 新建 / 打开 / 保存         |
| `Ctrl/⌘+Shift+S`        | 另存为                     |
| `Ctrl/⌘+W`             | 关闭当前标签               |
| `Ctrl/⌘+Z` / `Y`       | 撤销 / 重做                |
| `Ctrl/⌘+F` / `H`       | 查找 / 替换                |
| `F3` / `Shift+F3`      | 下一个 / 上一个匹配        |
| `Ctrl/⌘+D`             | 选中下一个相同词（多光标） |
| `Ctrl/⌘+/`             | 切换行注释                 |
| `Ctrl/⌘+,`             | 设置                       |

Markdown 文件下另有一套编辑快捷键（加粗、标题分级、列表等），只在 Markdown 文档里生效。
完整列表在「设置 → 快捷键」，可以改，也能查冲突。

## 配置放在哪

| 内容             | 位置                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------ |
| 配置文件         | Windows `%APPDATA%\com.fak.editor\`，macOS `~/Library/Application Support/com.fak.editor/` |
| 日志             | 同上目录下的 `logs/`                                                                       |
| 未保存内容的备份 | 同上目录下的 `backups/`                                                                    |

配置是一个 JSON 文件，可以直接用 Fak 自己打开编辑，改完即时生效，不必重启
（只有「单实例」这一项例外，它需要重启）。

「设置 → 关于」里有直达这两个目录的按钮。

## 隐私

无账号、无云同步、无遥测、无崩溃上报。

唯一的出网行为是**检查更新**，可以在设置里关掉，也可以单独配代理。

日志里不写文档正文、查找词、剪贴板内容、完整路径和任何凭据——
贴到 issue 上不会泄漏你在编辑什么。
