# Fak 功能清单

本文列出 Fak 面向用户的全部功能。**未实现**的条目单独标注，详细计划见 [TODO.md](./TODO.md)。

上手指引和快捷键见 [README.md](./README.md)。

> 标题里的 `F1`、`F16` 等编号是功能标识，源码注释里的「见 SPEC F13」指的就是它们。

---

## F1 · 文件与工作区

**打开与保存**

- 新建、打开、保存、另存为；拖放文件到窗口打开；最近文件列表。
- 保存是原子的：写临时文件再替换，进程被强杀也不会留下半截文件。
- 打开只读文件时明确提示，不会让你白改一通才发现存不进去。

**编码**

- 自动探测 UTF-8 / UTF-16 / GBK / GB2312 / Big5 以及带不带 BOM 的变体。
- 探测不准时可以「以指定编码重新打开」，也可以转换编码后另存。
- 状态栏常驻显示当前编码，点击即可切换。

**换行符**

- 自动识别 LF / CRLF / CR，状态栏显示并可一键转换。
- 新建文件用哪种换行符可在设置里指定。

**文件树侧栏**

- 打开文件夹作为工作区，树形浏览。
- 右键可新建、重命名、删除（进回收站）、复制路径、在文件管理器中显示。
- 跟随磁盘变化自动刷新；遵守 `.gitignore`，可选是否显示隐藏文件。
- 宽度可拖拽调整并记住。

**外部变更检测**

- 文件在应用外被修改时提示，提供重新加载或保留当前内容。
- 保存时若磁盘版本已变，会拦下来并可以直接看差异再决定。

**崩溃恢复**

- 未保存内容周期性自动备份。
- 崩溃或断电后下次启动列出可恢复的内容，逐项可预览差异后再决定恢复或丢弃。
- 大文件不做自动备份，状态栏会说明。

**会话恢复**

- 重启后恢复上次打开的标签页、标签锁定状态、光标位置、视口位置、代码折叠状态、
  工作区与侧栏状态。可在设置中关闭。

## F2 · 标签页

- 多标签，脏标记，中键关闭，拖拽排序。
- 右键菜单：锁定 / 取消锁定、关闭其他、关闭右侧、复制路径、在文件管理器中显示、
  设为对比源。
- 标签过多时出现左右滚动按钮。
- 关闭有未保存内容的标签会确认；多个文件时提供「全部保存 / 全部放弃」。
- 锁定标签不参与「关闭其他 / 关闭右侧」；中键与 `Ctrl/⌘+W` 不直接关闭锁定标签，
  但明确点击该标签的关闭按钮仍按正常流程关闭。

## F3 · 编辑器

**外观可调**：字体、字号、行高、字间距、连字、Tab 宽度、行号、当前行高亮、
缩进参考线、自动换行、竖标尺、光标样式与闪烁。

**编辑行为**

- 多光标：`Alt+单击` 加光标、`Ctrl/⌘+D` 选下一个相同词、`Ctrl/⌘+Shift+L` 选全部相同、
  `Alt+Shift+拖拽` 列选、`Alt+↑/↓` 移动行。
- `Ctrl/⌘+/` 按语言切换行注释。
- 括号匹配高亮；括号对按嵌套层级着色，颜色适配跟随系统、浅色、深色和高对比度主题。
- 完整档（Tier A）显示行号槽折叠箭头，支持折叠 / 展开当前区域、全部折叠 / 展开；
  折叠状态随会话保存。精简档与流式档不启用语法折叠。

**右键菜单**：剪切 / 复制 / 粘贴、撤销 / 重做、切换注释、折叠 / 展开、
美化 / 压缩、字数统计。

**剪贴板增强**：在 Markdown 里粘贴 URL 会自动套成链接；粘贴图片会存到文档同目录的
`assets/` 下并插入引用（未命名文档回退为内嵌）。

**撤销 / 重做**：连续输入合并为一步；替换全部无论改了多少处都只是一步。

## F4 · 查找、过滤与替换

**两套入口并存**：`Ctrl/⌘+F` 的轻量查找条，和 `Ctrl/⌘+Shift+F` 的高级面板。

**匹配模式**：纯文本、通配符、正则；可选区分大小写、全词匹配、跨行。

**文档内查找**

- 实时高亮全部命中，右侧概览标尺显示命中分布。
- 结果列表支持多选、连选、右键复制。
- 查找历史下拉，可清空。

**跨文件查找**

- 在工作区范围内搜索，支持包含 / 排除通配符、是否遵守 `.gitignore`、是否含隐藏文件。
- 结果按文件分组、分页加载，可随时取消，会报告跳过的文件与原因。

**替换**

- 单个替换、全部替换；支持正则捕获组与保留原大小写。
- 替换串里的 `\n`、`\t`、`\\` 等转义可选是否解释。
- **跨文件替换必须先看预览**：涉及哪些文件、各命中多少处、哪些会跳过，逐项可勾选，
  确认后才落盘。已打开且未保存的文件走内存修改，不会覆盖你正在编辑的内容。

**过滤模式**

- 只显示命中规则的行，规则可多条并存、着色、排序、反选（排除）、启停。
- 规则组可命名保存，重启后仍在；可导出 / 导入。
- 结果内可再筛一层。

## F5 · 差异对比

- 在两个标签间「设为对比源」→「与对比源比较」。
- 双栏并排，占位对齐，两侧都可编辑，可把一侧的块复制到另一侧。
- 行内字符级差异高亮。
- 比较选项：忽略空白、忽略大小写、忽略空行，选项会记住。
- 未保存的改动在行号槽显示变更色条。
- 大文件与流式文档退回只读并排。

## F6 · 大纲

- 基于语法解析，覆盖 19 种语言（含 JS/TS、Rust、Python、Go、Java、C/C++、C#、PHP、
  Kotlin、Swift、JSON、YAML、TOML、XML、INI、Markdown 等）。
- 树形展开 / 折叠，点击跳转，跟随光标高亮当前所在符号。
- 编辑时增量更新，只重算受影响的子树。
- 大文件下改为手动刷新；流式文档不提供大纲。

## F6.4 · 粘性滚动与面包屑

- 滚动时把当前所在的函数 / 类等父级符号固定在顶部。
- 面包屑显示符号链，点击任一级可展开同级列表并跳转。

## F7 · 书签

- 双击行号或用快捷键切换书签，行号槽显示标记。
- 书签面板列出全部书签，可跳转、逐个前后切换、一键清空。
- 随会话保存。

## F8 · Markdown

- 实时预览，支持编辑 / 分栏 / 仅预览三种布局。
- 编辑器与预览**双向滚动同步**。
- 代码块按语言着色，与编辑器共用同一套配色。
- 支持数学公式（KaTeX）与图表（Mermaid）。
- **默认拦截远程图片**，不发出网络请求；本地图片正常显示，但只允许文档目录内的路径。
- 工具栏：标题分级、粗体、斜体、删除线、行内代码、代码块、引用、有序 / 无序 / 任务列表、
  链接、图片、表格、分隔线、缩进 / 取消缩进、上下标。
- ❌ **不做**：下划线与前景 / 背景色。Markdown 没有对应语法，只能靠内联 HTML，
  而预览会把裸 HTML 转义成文本，做出来只会在预览里显示成标签字面量。

## F9 · 文本处理工具

- **格式化 / 压缩**：JSON、JSONC（保留注释）、YAML、XML、HTML、TOML。
  报错带行列位置。
- **文档清理**：去空行、去重复行、去首尾空格。
- **排序**：升序 / 降序、区分或忽略大小写、按拼音。
- **大小写转换**：大写、小写、标题式、驼峰、下划线、短横线。
- **Base64** 编解码，可直接输出到剪贴板。
- **缩进转换**：Tab ↔ 空格。
- **字数统计**：词数、字符数、不含空格字符数、行数、段落数，中文按字计。
- ❌ **未实现**：翻译。

## F16 · 大文件与日志跟随

Fak 按文件大小与行宽自动分三档，**当前档位始终显示在状态栏**，点击可看本档关闭了哪些功能、
为什么、以及如何提升档位。不做「越用越卡」的静默降级。

|                      | 完整                     | 精简     | 流式                            |
| -------------------- | ------------------------ | -------- | ------------------------------- |
| 进入条件             | ≤ 8 MiB 且最长行 ≤ 8 KiB | ≤ 64 MiB | 更大，或超长行，或超过 200 万行 |
| 自由编辑             | ✅                       | ✅       | ❌                              |
| 语法高亮             | ✅                       | 仅视口   | ❌                              |
| 查找 / 过滤          | ✅                       | ✅       | ✅                              |
| 大纲 / Markdown 预览 | ✅                       | 手动刷新 | ❌                              |
| 小地图               | 行长度 + 标记            | 仅标记   | 仅标记                          |
| 跟随模式             | —                        | —        | ✅                              |

**流式档专有能力**

- 只加载视口附近的行，1 GB 文件也能打开、滚动、跳转（按行号或百分比）。
- 全文查找：流式扫描，不加载全文，可取消。
- **跟随模式（tail -f）**：自动滚到末尾；向上滚动即暂停并提示「N 条新行」，
  点击恢复；日志被轮转截断时能自动重建。
- 可手动「载入为可编辑」提升档位，提升前会告知预计内存占用。
- ❌ **未实现**：流式档内的定点编辑与撤销 / 重做。

## 小地图

- 编辑器右侧的全文概览，显示行长度分布、未保存变更标记、查找命中标记。
- 点击或拖动跳转。
- 不渲染真实文本，所以大文件下不卡。
- 可关闭，也可设为仅在鼠标悬停时显示。

## F10 · 状态栏、界面与外观

- 四档主题：跟随系统、浅色、深色、高对比度。
- 三档密度：紧凑、标准、宽松。
- 界面语言：简体中文 / English，切换即时生效。
- 工具栏以图标为主，每个图标按钮都有 tooltip、无障碍标签，并且能在命令面板里按名字找到。

## F13 / F14 · 命令面板与快捷键

- `Ctrl/⌘+Shift+P` 唤起，**应用内每一个功能都能在这里搜到**。
- 子序列模糊匹配，中文命令同时匹配拼音首字母；显示所属分类与已绑定的快捷键。
- 快捷键可在设置中查看、修改、检测冲突、取消绑定、恢复默认，支持组合键序列。

## F12 · 鼠标手势

- 按住右键拖动触发，方向序列（上 / 下 / 左 / 右）可自定义绑定到任意命令。
- 拖动过程中显示当前识别到的手势与将要触发的动作。
- 可整体关闭。

## F15 · 外部工具

- 自定义外部命令，把当前文档或选区交给它处理。
- 输出可以替换选区、开新标签，或只做预览。
- **首次运行必须确认**，并原样展示将要执行的完整命令；可选「不再询问」。
- 工具定义可导出 / 导入。

## F11 · 设置

分组覆盖：常规、外观、编辑、查找与差异、Markdown、鼠标手势、更新、外部工具、关于。

- 支持搜索设置项，按分组展示并高亮命中。
- 配置文件可直接编辑，改完即时生效（单实例开关除外，需重启）。

## 系统集成

- **Windows**：可在设置里注册右键菜单「用 Fak 打开」与文件关联。
  只写当前用户的注册表，不需要管理员权限，不改动已有的默认打开方式，可一键还原。
- **macOS**：支持双击与「打开方式」打开文件。
- **单实例**（默认开启）：再次打开文件时在已有窗口新建标签，而不是另开进程。可关闭，改后需重启。
- ❌ **未实现**：Linux 的 `.desktop` 与 MIME 关联。

## 更新

- 应用内检查更新，可关闭自动检查（每天最多一次）。
- 支持独立的更新代理（http / https / socks5 / socks5h），带「测试连接」按钮；
  两种 SOCKS 前缀均有本地真实握手与转发测试覆盖。
- 发现新版本后一键完成下载、安装、重启；有未保存内容时先提示保存。
- 可「稍后提醒」或「跳过此版本」。
- 安装包签名校验失败一律中止，不提供忽略选项；安装目录不可写时引导手动下载，绝不请求提权。

## 隐私

- 无账号、无云、无遥测、无崩溃上报。
- 唯一出网行为是检查更新，可关闭并可单独配代理。
- 日志中不含文档正文、查找词、剪贴板内容、完整路径、代理地址与任何凭据。
